ℹ️ MontageAI

    
Outil web qui génère des pubs vidéo verticales pour réseaux sociaux. 100 % gratuit, 100 % dans ton navigateur.


    
Comment ça marche

    
    
      
  1. Tu mets tes propres clés API (Pexels, Pixabay, ElevenLabs) — gratuit pour tout le monde
    2. 
      
  2. Tu écris ton script (ou tu pioches un modèle)
    3. 
      
  3. Tu uploades tes screenshots ou tu décris du stock à chercher
    4. 
      
  4. L'app appelle les APIs depuis ton navigateur — aucun backend, aucune fuite de clé
    5. 
      
  5. FFmpeg.wasm compose la vidéo localement — ton CPU, ton navigateur
    6. 
      
  6. Tu télécharges le MP4
    7. 
    


    
Tarifs

    
L'app est gratuite. Les APIs externes :

    
    
      
  • Pexels : gratuit illimité (rate-limit raisonnable)

  • Pixabay : gratuit illimité (100 req/min)
